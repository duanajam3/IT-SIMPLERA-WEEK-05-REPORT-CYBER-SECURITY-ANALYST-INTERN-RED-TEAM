# IT-SIMPLERA-WEEK-05-REPORT-CYBER-SECURITY-ANALYST-INTERN-RED-TEAM

This report presents the network enumeration and vulnerability assessment performed on the assigned Metasploitable 2 target using Nmap. Different Nmap scan types were used to identify open ports, running services, service versions, and the operating system. The collected information was analyzed to understand the target's attack surface, identify potential vulnerabilities, and recommend security improvements. All activities were conducted in an authorized lab environment for educational purposes.
